# n8n Google OAuth2 Login

Пример страницы авторизации для n8n-сервера с поддержкой входа через Google OAuth2. Backend написан на Node.js/Express, фронтенд — статическая страница на чистом JavaScript.

## Возможности

- Стартовая страница `/` с кнопкой «Войти через Google»
- Проверка состояния сессии и редирект авторизованных пользователей на `/dashboard`
- Обработка OAuth2, хранение access/refresh токенов в защищённой cookie-сессии
- Автоматическое обновление access-токена при обращении к API
- Получение базового профиля Google и вывод на дашборде
- Выход из системы с очисткой сессии

## Быстрый старт

1. Скопируйте `.env.example` в `.env` и заполните значения:
   ```bash
   cp .env.example .env
   ```
   Необходимо получить `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET` в [Google Cloud Console](https://console.cloud.google.com/). Укажите `GOOGLE_REDIRECT_URI`, совпадающий с URL `/auth/google/callback` вашего сервера.

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер в режиме разработки:
   ```bash
   npm run dev
   ```

   По умолчанию сервер поднимется на `http://localhost:3000`.

## Переменные окружения

| Переменная | Описание |
| --- | --- |
| `GOOGLE_CLIENT_ID` | Идентификатор OAuth 2.0 клиента Google |
| `GOOGLE_CLIENT_SECRET` | Секрет OAuth 2.0 клиента |
| `GOOGLE_REDIRECT_URI` | Redirect URI, зарегистрированный в Google Console |
| `SESSION_SECRET` | Строка для подписи cookie-сессии (обязательно задайте сильное значение) |
| `PORT` | Порт запуска Express сервера (по умолчанию `3000`) |
| `DASHBOARD_REDIRECT` | URL, на который происходит редирект после успешного входа |

## Интеграция с n8n

Проект можно задеплоить рядом с вашим n8n-инстансом и настроить проксирование, например, через Nginx или Railway. После авторизации вы можете использовать полученный refresh токен Google для нод n8n или сохранить его в базу данных по своему сценарию.

## Безопасность

- Токены Google хранятся в HTTP-only cookie сессии и не доступны из JavaScript
- Добавлена проверка `state` для защиты от CSRF
- Access-токен автоматически обновляется с использованием refresh-токена перед обращением к API
